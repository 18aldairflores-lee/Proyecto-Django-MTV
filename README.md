# Proyecto Django MTV - ComunidadConectada

Aplicación web back-end desarrollada con Django 5 aplicando el patrón arquitectónico MTV (Model-Template-View).

## Características
- Entorno virtual aislado y configuración modular (config + app comunidad).
- Modelo Servicio gestionado mediante Django ORM y Panel Administrativo.
- Herencia de plantillas HTML (base.html) con interfaz moderna en modo oscuro.
- Formulario web con protección CSRF para registrar servicios y cambio de estado dinámico.
